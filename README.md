# File & AI Content Assistant

一个专为与网页版AI交互设计的文件内容管理工具，轻松收集项目目录结构和文件内容，一键复制后即可发送给AI进行代码分析、需求分析等。

## 为什么制作这个软件

在使用网页版AI（如ChatGPT、Claude、Gemini等）进行开发时，经常需要：
- 📂 给AI展示项目目录结构，让AI了解项目整体架构
- 📄 分享多个文件的内容，让AI进行代码审查或功能开发
- 🚫 排除不必要的文件（如node_modules、构建产物等）
- ⚡ 快速复制格式化后的内容，避免手动整理

这个工具就是为了解决这些痛点而制作的！

## 功能特性

### 目录树页面
- 📁 浏览目录结构，支持双击展开/折叠
- 🖱️ 单击选中、Ctrl+单击多选、框选
- 🚫 右键排除/取消排除文件或文件夹（排除文件夹自动包含子内容）
- 📋 复制当前树结构文本，方便发送给AI
- 🎯 支持按文件类型过滤显示

### 文件内容页面
- 📂 使用目录树页面选择的文件夹
- 📄 右键添加选择文件或打开文件选择对话框
- 🔍 自动识别文件编码（支持各种编码格式）
- 📋 一键复制单个或全部文件内容，自动格式化
- 💾 复制格式统一，包含文件路径和内容，AI友好
- ✨ 目录树展开/折叠状态在软件生命周期中保持

### 已排除列表面板
- 📝 在目录树页面右侧显示已排除项
- 🗑️ 支持选择和清除单个或全部排除项

### 用户体验
- 🍞 复制操作有优雅的右上角悬浮提示（最多5个）
- 🎨 深色主题，护眼舒适
- ⚡ 响应式设计，流畅交互

## 使用场景示例

1. **代码审查**: 选择项目目录，排除无关文件，复制目录树和相关代码文件，发送给AI进行代码审查
2. **功能开发**: 分享当前项目结构和现有代码，让AI帮你规划新功能
3. **bug修复**: 把相关文件内容复制给AI，描述问题，让AI帮忙分析
4. **文档生成**: 让AI根据代码结构生成项目文档

## 安装与运行

### 安装依赖
```bash
npm install
```

### 运行应用
```bash
npm start
```

## 技术栈

- **Electron**: 跨平台桌面应用框架
- **jschardet**: 编码检测
- **iconv-lite**: 编码转换
- **HTML/CSS/JavaScript**: 原生前端技术

## 开发工具

本项目使用 **TraeCN** AI 编程助手进行开发，这是一个强大的 AI 驱动的编程工具，帮助开发者快速构建应用。

```
---------------
下一个文件路径
---------------
...
```
